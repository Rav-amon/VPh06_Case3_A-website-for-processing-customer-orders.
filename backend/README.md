# Backend

Приватный API заявок. Контейнер подключён к сетям `app` и `data`. Ключа `ports` в compose нет, поэтому порт `8000` на хосте не слушается.

Роль базы — `LEADS_APP_USER`. Пароль берётся из `.env` и в код не записывается.

## Таблицы

| Модель | Таблица | Смысл |
|---|---|---|
| `Lead` | `leads` | анкета клиента |
| `LeadBehavior` | `lead_behavior` | метрики страницы, первичный ключ = `leads.id` |
| `AdminSettings` | `admin_settings` | услуги и диапазон бюджета, одна строка |

SQL каждой таблицы записан в докстринге класса. При старте процесс выполняет его и создаёт строку настроек, если её ещё нет. Диапазон по умолчанию: от `0` до `1000000` с шагом `10000`. Список услуг пустой, пока его не заменят.

## Ответ

Успех: `{ "data": ..., "error": null, "message": "..." }`.

Ошибка: `{ "data": null, "error": { "code", "message", "details" }, "message": "..." }`.
